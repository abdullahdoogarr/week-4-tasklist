# Week 4: Control Flow and Loops

Ten exercises on `if`/`elif`/`else`, `for` and `while` loops, nested loops, `break`, `continue`, and logical conditions. They're interactive, so run them and type input when prompted.

| File | Topic |
|------|-------|
| `task1_student_grading.py` | Validate marks, assign grades, pass/fail counts, highest and average |
| `task2_atm_simulation.py` | Menu-driven ATM with balance checks |
| `task3_prime_numbers.py` | Primes in a range with count and sum |
| `task4_password_authentication.py` | Login with three attempts and account lock |
| `task5_number_guessing.py` | Guess 1-100 in seven attempts |
| `task6_electricity_bill.py` | Progressive-rate bills until -1 |
| `task7_pattern_generation.py` | Number patterns and multiplication table |
| `task8_inventory_management.py` | Stock tracking with `continue` for invalid sales |
| `task9_fibonacci.py` | Fibonacci terms, sum, even/odd counts |
| `task10_number_analysis.py` | Even/odd, largest, sum and average until 0 |

Run any task with:

```bash
python3 task1_student_grading.py
```
